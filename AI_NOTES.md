# AI_NOTES

**Инструменты.** Claude Code (облачная сессия на claude.ai/code) — единственный coding agent. Журнал запросов — `AI_PROMPTS.md` (пишется автоматически hook-ом `UserPromptSubmit`, ответы на уточняющие вопросы агента дописаны вручную).

**Как работали.** Сначала — отдельная сессия проектирования без кода: агент составил список из ~25 архитектурных решений и задавал вопросы блоками, по каждому — варианты с рекомендацией. Решения зафиксированы в `docs/decisions.md` и `CLAUDE.md` и дальше служили контекстом для реализации. Реализация шла фазами, по коммиту на фазу, с тестами на каждой.

**Что спроектировал сам.** Правило сторно для возвратов и дополнительные расходы на возврат в модели; вариант «товар потерян» наряду с возвратом на склад; периоды в поясе браузера; состав карточки «лучший менеджер». Где отклонил рекомендацию агента: Controllers вместо Minimal API, без денормализации итогов на `Sale`, Nivo вместо Recharts, добавил Playwright e2e. На вопросе про enum попросил агента исследовать актуальные версии C#/EF — в итоге выбрали нативные PG enum через `MapEnum`, union types C# 15 отклонили как preview.

**Что делегировал.** Весь код: каркас, доменную модель и миграции, генератор seed, SQL-агрегаты, API, UI, тесты, Docker, README.

**Где AI заметно ускорил.** Каркас стека и Docker за минуты; генератор реалистичных данных с профилями менеджеров и сезонностью; сценарный интеграционный тест с вручную посчитанными ожиданиями; вёрстка всех блоков с состояниями.

**Где AI ошибался (и как это поймали).**
- Timeseries падал с 500: Npgsql передавал локальный `DateTime` как `timestamptz` — пойман ручной проверкой эндпоинтов через curl до написания тестов.
- Первая версия seed давала 50-кратный разрыв средних чеков между командами — заметили по SQL-распределению, сгладили формулу объёма.
- shadcn CLI сгенерировал компоненты с битым импортом `from "cn"`; шрифт Geist не содержит кириллицы — оба пойманы на сборке и скриншотах.
- Спарклайны наезжали на подписи KPI, длинная подпись ломала колонку рейтинга — пойманы по скриншотам Playwright.
- Hook сначала писал время в UTC контейнера — исправлено на МСК.

**Что изменил или отклонил из предложений агента.** Изначально в решениях был комбинированный график с двумя осями Y; при реализации заменили на один денежный график + отдельную полосу количества продаж (две шкалы на одном графике вводят в заблуждение) — отступление записано в `docs/decisions.md`.

**Как проверял результат.** 47 backend-тестов (включая интеграционные на реальном PostgreSQL), 11 frontend-тестов, 4 e2e; сверка сумм: график и категории = KPI; `EXPLAIN ANALYZE` ключевых запросов; скриншоты в светлой и тёмной теме на 1440×900; валидатор палитры графиков на контраст и различимость при дальтонизме.
